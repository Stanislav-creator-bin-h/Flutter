 LR03: Простий UI — User Profile Card
Лабораторна робота з курсу "Основи Flutter". Створення візитки користувача з використанням базових віджетів Layout та Material Design 3.
---
 Мета роботи
Навчитися будувати інтерфейси у Flutter, поєднуючи базові компоненти:

Робота з Layout (Column, Row, Container).

Стилізація через ThemeData та Material Design 3.

Створення адаптивного інтерфейсу за допомогою SingleChildScrollView.

Декомпозиція UI на окремі методи та віджети.
---
 Самоперевірка
- Яка різниця між Column та Row?
Column розміщує елементи вертикально, а Row — горизонтально.

- Навіщо Theme.of(context)?
Щоб отримати поточні стилі застосунку (кольори, шрифти) і використовувати їх у UI.

- Що робить mainAxisSize: MainAxisSize.min?
Зменшує розмір віджета до мінімально необхідного, щоб не займати весь доступний простір.

- Навіщо SingleChildScrollView?
Щоб екран можна було прокручувати, якщо контент не вміщається на екрані.
