---

ListView vs ListView.builder — ListView одразу створює всі елементи, builder створює тільки ті що видно на екрані, тому швидший.
Key в Dismissible — щоб Flutter знав який саме елемент видаляти, без key може видалити не той.
setState() — каже Flutter що дані змінились і треба перемалювати UI.
dispose() контролера — щоб не було витоку пам'яті коли екран закривається.
