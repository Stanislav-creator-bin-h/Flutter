# Smart Wallet | Flutter Expense Tracker

> Комплексний навчальний проєкт з основ Flutter (LR06: REVIEW Session, Блок 1, Варіант A). Додаток створений для зручного та швидкого контролю за щоденними фінансами.

---

## Про проєкт

Цей застосунок дозволяє користувачеві легко записувати свої витрати, розбивати їх за категоріями та слідкувати за загальною статистикою. Особлива увага в проєкті приділена правильній архітектурі, роботі зі станом та створенню перевикористовуваних UI-компонентів.

### Головні фічі
-  **Швидке додавання:** Зручна форма для запису нових транзакцій із вбудованою перевіркою (валідацією) введених даних.
-  **Інтуїтивне управління:** Видалення будь-якої витрати відбувається звичним жестом свайпу вліво (використано `Dismissible`).
-  **Категоризація:** Усі витрати сортуються за 4 основними напрямками (🍔 Food, 🚗 Transport, 🛍️ Shopping, 📦 Other).
-  **Автоматична статистика:** Додаток самостійно рахує загальні витрати та виводить суму по кожній окремій категорії на головному екрані.
-  **Деталізація:** Клік по картці категорії відкриває окремий екран з історією покупок виключно для цього напрямку.
-  **Бонус (Empty State):** Жодних порожніх і нудних екранів! Якщо список транзакцій пустий, користувач бачить гарний віджет із закликом додати перший запис.

##  Використані технології та підходи

Проєкт побудований на базових принципах фреймворку Flutter без використання сторонніх пакетів (Pure Flutter):

* **Моделювання даних:** Використання можливостей Dart OOP. Застосовано зв'язку `enum` + `extension` для жорсткої типізації категорій та їхнього візуального оформлення.
* **State Management:** Локальне управління станом реалізовано через `StatefulWidget` та метод `setState()`.
* **Оптимізація UI:** 
  * `ListView.builder` — для плавної прокрутки історії (елементи створюються лише тоді, коли видимі на екрані).
  * `GridView.count` — для побудови адаптивної сітки категорій.
* **Навігація:** Стандартний роутинг екранів (стековий `Navigator`).
* **Дизайн:** Material Design 3, кастомні віджети (створено незалежний компонент `CategoryCard` для чистоти коду).
